A machine learning pipeline to predict whether a molecule is **Toxic** or **NonToxic** using molecular descriptors. The pipeline covers end-to-end steps: exploratory data analysis, preprocessing, feature selection, and cross-validated model evaluation.

## 3. Exploratory Data Analysis (EDA)

### 3.1 Class Distribution
The dataset is moderately imbalanced with **67.3% NonToxic** and **32.7% Toxic** compounds. This imbalance was addressed during modeling using SMOTE oversampling applied strictly within each cross-validation fold to prevent data leakage.

### 3.2 Feature Distributions
Histograms of sampled features revealed that a large proportion of molecular descriptors are **heavily right-skewed**, which is typical for molecular descriptor datasets. Many features showed sparse distributions with a majority of zero values.

### 3.3 Skewness Analysis
Features were assessed for skewness across the full feature set. A large number of features showed absolute skewness greater than 2, indicating non-normal distributions. `RobustScaler` was chosen during preprocessing to handle this, as it is resistant to outliers and does not assume normality.

### 3.4 Zero and Near-Zero Variance
Several features were identified as constant or near-constant across all sample and were removed using `VarianceThreshold`.

### 3.5 Correlation Analysis
A pairwise Pearson correlation analysis across all features identified a large number of highly correlated feature pairs. These redundant features were removed to reduce multicollinearity and dimensionality before feature selection.

### 3.6 Class Separation (PCA)
A 2D PCA visualization of the feature-selected data showed partial but meaningful separation between Toxic and NonToxic classes, confirming that the selected features carry discriminative signal.


## 4. Preprocessing

Preprocessing was applied in the following order to prepare the data for modeling:

### 4.1 Target Encoding
The `Class` column was label-encoded:
- `NonToxic → 0`
- `Toxic → 1`

### 4.2 Missing Values
No missing values were present in this dataset.

### 4.3 Variance Threshold
Features with variance below 0.01 were removed using `VarianceThreshold`. This step eliminates constant and near-constant features that provide no discriminative power.

### 4.4 High-Correlation Removal
Features with pairwise Pearson correlation above 0.95 were identified and one from each correlated pair was dropped. This reduces redundancy and multicollinearity.

## 5. Feature Selection

Given the high dimensionality (1,203 features) relative to the small sample size (171 samples), feature selection was critical to prevent overfitting. 

### 5.1 Method 1 — ANOVA F-Score (Univariate Filter)
`SelectKBest` with `f_classif` was used to rank features.

### 5.2 Method 2 — Mutual Information
`SelectKBest` with `mutual_info_classif` was used to capture non-linear dependencies between each feature and the target.

### 5.3 Method 3 — ExtraTrees Feature Importance
An `ExtraTreesClassifier` was trained on the full preprocessed feature set and feature importances were extracted. 

### 5.4 Consensus Voting
The top 50 features from each method were identified. A feature was retained in the **final selected set** only if it appeared in the top 50 of **at least 2 out of 3 methods**. This consensus approach is more robust than any single method alone, reducing the risk of selecting noise features that rank highly in
Given the class imbalance, accuracy alone is misleading. The following metrics were used:

- **ROC-AUC** — measures overall discriminative ability regardless of threshold
- **F1-Score (macro)** — balances precision and recall across both classes equally
- **F1-Score (Toxic class)** — specifically measures performance on the minority class, which is the class of greatest interest in toxicity prediction

## 8. Key Design Decisions

| SMOTE inside CV loop - Prevents synthetic samples from leaking into validation folds |
| RobustScaler over StandardScaler - Molecular descriptors have heavy outliers; RobustScaler is resistant to these 
| Consensus feature selection - More robust than any single method; reduces chance of selecting noise features 
| StratifiedKFold - Preserves class ratio across folds given the 2:1 imbalance |
| ROC-AUC as primary metric - More informative than accuracy for imbalanced binary classification 
| ExtraTrees for importance - Captures feature interactions unlike univariate filter method(ANOVA)
